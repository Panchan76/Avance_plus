# Avance+ — atualização visual

Paleta: azul-marinho `#142D4E`, azul principal `#2563EB`, azul-claro `#60A5FA`, fundo `#F8FAFC`, branco `#FFFFFF`.

## O que mudou
- Tema Material 3 centralizado em `lib/core/theme/app_theme.dart`.
- Estilos globais de botões, campos, cartões, títulos, barra de navegação, ícones, avisos e diálogos.
- Tela de boas-vindas com identidade visual e mensagens atualizadas.
- Bordas dos cards e seleção de tipo de conta harmonizadas.

## O que não mudou
- Serviços, autenticação, Firebase, Gemini, modelos de dados, rotas e regras de negócio.
- A configuração de texto ampliado foi mantida.

## Como executar
```bash
flutter pub get
flutter analyze
flutter run
```

**Observação:** não foi possível executar o Flutter neste ambiente. Teste em Android e Web antes de publicar.
